# Home Assistant on Windows

A simple guide for trying [Home Assistant](https://www.home-assistant.io/) on your own Windows PC before buying any hardware.

## What's in this repo

| File | What it is |
| --- | --- |
| `index.html` | Step-by-step guide to running Home Assistant on Windows with Docker Desktop and PowerShell. No Linux knowledge needed. |
| `protocols.html` | Zigbee, Wi-Fi, Matter, Z-Wave, Thread and Bluetooth compared, which one to pick for new devices, and the extra hardware you need for a Home Assistant Green, Yellow or mini PC. |
| `ha.ps1` | PowerShell script to start, stop, update and remove Home Assistant with one short command. |

## Why

Home Assistant usually runs on a small always-on device. This guide lets you try it first on the PC you already have, in about 30 minutes, and remove it just as easily. When you're ready to buy hardware, the protocols page helps you choose what to get.
