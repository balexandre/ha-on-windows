Home Assistant on Windows

Try Home Assistant on your own PC with Docker Desktop and PowerShell, before buying any hardware.

Planning what to buy? Read Smart home protocols: Zigbee, Wi-Fi, Matter, Z-Wave, Thread and Bluetooth compared, plus the extra hardware you need.

About 30 minutesmost of it is downloading
FreeDocker Desktop is free for home use
Easy to undoone folder and one container

Before you start

  • Windows 10 (22H2) or Windows 11, with administrator rights.
  • About 5 GB free disk space.
  • The PC must stay on while you use Home Assistant. If it sleeps or shuts down, so does Home Assistant.
  • All commands below go into PowerShell. Open it from the Start menu: type PowerShell and press Enter. No WSL or Linux knowledge needed.
1

Install Docker Desktop

Download it from docker.com/products/docker-desktop and run the installer. Keep the default options, including “Use WSL 2”. Docker uses this behind the scenes; you never have to open it yourself.

Restart the PC when asked, then open Docker Desktop from the Start menu. Accept the terms. You can skip signing in.

What to expectThe first start can take a couple of minutes. It may ask to install or update WSL; say yes. When the whale icon in the taskbar tray stops animating and Docker Desktop shows “Engine running”, it's ready.
If it complains about virtualizationVirtualization is switched off in the PC's BIOS/UEFI settings. Look for Intel VT-x, Intel Virtualization Technology or AMD SVM, switch it on, and restart.

Check that Docker works. Open PowerShell and run:

PowerShell
docker version

You should see a Client and a Server section. If it says the command isn't found, close PowerShell and open it again.

2

Create a folder for Home Assistant's settings

Everything Home Assistant saves (your account, devices, dashboards) goes in this folder, so it survives restarts and updates.

Prefer fewer commands? The ha.ps1 script below does steps 2–4 for you.

PowerShell
New-Item -ItemType Directory -Force "$env:USERPROFILE\HomeAssistant\config"
What to expectA new folder C:\Users\<you>\HomeAssistant\config. It's empty for now; Home Assistant fills it on first start.
3

Start Home Assistant

Paste the whole block into PowerShell and press Enter. If you don't live in Denmark, change Europe/Copenhagen to your own time zone first, e.g. Europe/Lisbon or Europe/London.

PowerShell
docker run -d `
  --name homeassistant `
  --restart=unless-stopped `
  -e TZ=Europe/Copenhagen `
  -v "$env:USERPROFILE\HomeAssistant\config:/config" `
  -p 8123:8123 `
  ghcr.io/home-assistant/home-assistant:stable
What to expectDocker first downloads Home Assistant, about 1–2 GB, with progress bars. Then it prints one long line of letters and numbers: that's the new container's ID, and it means Home Assistant is starting. Docker Desktop's Containers tab now shows homeassistant with a green dot.

The backticks ` at the end of the lines tell PowerShell that the command continues on the next line. This is the only time you need this long command.

4

Open Home Assistant and create your account

Wait 1–3 minutes, then open http://localhost:8123 in your browser.

What to expect First you may see “Preparing Home Assistant” or a page that won't load yet. That's normal on the first start; refresh after a minute. Then the welcome screen asks you to:
  • Create your user: name, username and password. This account only exists on your PC.
  • Set your home location: used for weather, sunrise and sunset.
  • Choose analytics: sharing is optional.
  • See devices it found, if any (see “Adding your devices” below).
Windows Firewall pop-upWindows may ask whether Docker can use the network. Tick Private networks and click Allow. This also lets you open Home Assistant from your phone (see below).
5

Adding your devices

Go to Settings → Devices & services. Devices Home Assistant found show up under Discovered; click Add on each. To add something else, click + Add integration (bottom right) and search for the brand: Philips Hue, Sonos, Shelly, Google Cast, IKEA, TP-Link and so on.

Most devices won't be discovered automatically Docker Desktop keeps Home Assistant in its own small private network, so the “I'm here” announcements from Hue, Sonos, Chromecast and similar don't reach it. They still work: add them by hand with + Add integration, and when asked, type the device's IP address. You can find these in your router's list of connected devices, or in the device's own app (e.g. Hue app → Settings → Hue Bridges → ⓘ).

Cloud-based brands (e.g. Google Nest, Tuya/Smart Life, Netatmo) don't need discovery: you sign in with that brand's account.

Shortcut: the ha.ps1 script

ha.ps1 does steps 2–4 and everything under “Everyday use” with short commands. It starts Docker Desktop if it isn't running, creates Home Assistant the first time, waits until it's ready, and opens it in your browser.

Put ha.ps1 in C:\Users\<you>\HomeAssistant, then in PowerShell:

PowerShell
cd "$env:USERPROFILE\HomeAssistant"
powershell -ExecutionPolicy Bypass -File .\ha.ps1 start
What to expectThe first time, it downloads Home Assistant and prints dots while it waits for it to start. When it's ready, it prints the addresses for this PC and your phone, and opens your browser.
CommandWhat it does
startCreate (first time) or start Home Assistant, then open it
stopStop Home Assistant
restartStop and start again
statusIs it running? Shows the addresses for this PC and your phone
logsShow the log; Ctrl+C to stop watching
updateDownload the newest version and restart with your settings
removeDelete the container; your settings folder is kept
openOpen Home Assistant in the browser
Why the long “-ExecutionPolicy Bypass” part?Windows blocks scripts by default. That part allows just this one run. To be able to type the short .\ha.ps1 stop from now on, run these two lines once. They allow scripts you created yourself, and unblock this downloaded one:
PowerShell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
Unblock-File "$env:USERPROFILE\HomeAssistant\ha.ps1"

To change the time zone or port, open ha.ps1 in Notepad and edit the lines under “Settings you may want to change” at the top.

Everyday use

Home Assistant starts by itself whenever Docker Desktop is running. To have it running after every reboot, turn on Docker Desktop → Settings → General → “Start Docker Desktop when you sign in”.

The easiest way to stop and start it is the ha.ps1 script above, or the Containers tab in Docker Desktop: use the ▶ and ■ buttons next to homeassistant. Or type the Docker commands in PowerShell yourself:

To…Run in PowerShell
Stopdocker stop homeassistant
Start againdocker start homeassistant
Restartdocker restart homeassistant
Check if it's runningdocker ps -a --filter name=homeassistant
“Up …” = running, “Exited” = stopped
See the log (when something is wrong)docker logs -f --tail 100 homeassistant
press Ctrl+C to stop watching; Home Assistant keeps running

Use it from your phone

Find the PC's address on your home network:

PowerShell
(Get-NetIPAddress -AddressFamily IPv4 | Where-Object { $_.PrefixOrigin -eq 'Dhcp' }).IPAddress

On a phone connected to the same Wi-Fi, open http://<that address>:8123, e.g. http://192.168.1.25:8123. Or install the Home Assistant app from the App Store or Google Play and enter the same address.

Update to the newest version

A new Home Assistant version comes out every month. To update, download the new version, remove the old container, then run the long command from step 3 again. Your settings are in the folder from step 2, so nothing is lost.

PowerShell
docker pull ghcr.io/home-assistant/home-assistant:stable
docker rm -f homeassistant

If something goes wrong

You seeTry this
docker isn't recognized, or “cannot connect to the Docker daemon”Docker Desktop isn't running. Open it from the Start menu, wait for “Engine running”, then open a new PowerShell window.
“The container name "/homeassistant" is already in use”It's already created. Just run docker start homeassistant.
“port is already allocated”Something else is using port 8123. Change -p 8123:8123 to -p 8124:8123 and use http://localhost:8124.
The page doesn't loadWait two minutes and refresh. Still nothing? Look at the log: docker logs --tail 50 homeassistant.
The phone can't connectCheck the phone is on the same Wi-Fi. In Windows Firewall, allow Docker Desktop Backend on private networks, and make sure your Wi-Fi is set to Private, not Public.

Good to know

  • USB sticks (Zigbee, Z-Wave, Bluetooth) don't work in this setup. Docker Desktop can't pass USB devices to Home Assistant. Wi-Fi and cloud devices are fine. Not sure what Zigbee, Thread or Matter are? See Smart home protocols.
  • This is for trying it out. If you like it, a small always-on device (Home Assistant Green, a Raspberry Pi or a mini PC) is better: it uses little power, finds devices automatically and supports USB sticks and add-ons. You can move your setup over with a backup: Settings → System → Backups.
  • Make a backup of the HomeAssistant folder from time to time. That folder is your Home Assistant.

Remove everything

To remove the container and its download:

PowerShell
docker rm -f homeassistant
docker image rm ghcr.io/home-assistant/home-assistant:stable

Then delete the folder C:\Users\<you>\HomeAssistant, and uninstall Docker Desktop from Settings → Apps if you don't need it anymore.
